01 설치

공식 사이트에서 무료로 받을 수 있어요. 설치 후 반드시 재부팅이 필요합니다.

VB-Audio 공식 사이트에서 다운로드

아래 링크에서 "Download" 버튼을 눌러 zip 파일을 받으세요.

vb-audio.com/Cable →

받은 zip을 압축 풀고, 안에 있는 VBCABLE_Setup_x64.exe를 관리자 권한으로 실행하세요 (우클릭 → "관리자 권한으로 실행").

⚠ 설치 후 필수
설치가 끝나면 반드시 컴퓨터를 재부팅하세요. 재부팅 안 하면 장치가 목록에 안 뜨거나 소리가 하나도 안 잡히는 경우가 많아요.

02 시스템 소리를 CABLE로 보내기

Windows가 소리를 스피커 대신 VB-Cable로 흘려보내도록 지정하는 단계예요.

출력 장치를 CABLE Input으로 변경
설정› 시스템› 소리› 소리를 재생할 위치 선택

여기서 CABLE Input (VB-Audio Virtual Cable)를 선택하세요.

🔇 부작용 - 내 귀엔 안 들려요
이렇게 하면 소리가 전부 CABLE로만 가서, 스피커/헤드폰으로는 소리가 안 나요. STT는 잘 되는데 사람이 들을 수 없는 상태가 되는 거예요. 아래 03단계에서 이 문제를 해결해요.

03 내 귀에도 들리게 만들기

STT는 계속 잡히면서, 동시에 스피커로도 소리가 나가게 하는 설정이에요. 여기서 실수하면 오히려 소리가 울리거나 삐- 하는 피드백음이 날 수 있어요.

"이 장치 청취" 켜기
소리 설정› 녹음 탭› CABLE Output 우클릭› 속성› 청취 탭

이 장치를 청취합니다 체크 → 재생 장치를 내 실제 스피커/헤드폰으로 지정하세요.

⚠ 딱 한 곳에서만 켜세요
"청취"는 CABLE Output에서만 켜야 해요. 만약 재생 장치를 실수로 CABLE Input 자신으로 지정하면, 소리가 스스로를 계속 되돌리면서 삐- 하는 피드백음(경보음처럼 들림)이 날 수 있어요. 이런 소리가 나면 바로 이 "청취" 체크를 끄고 재확인하세요.

04 STT 앱에서 마이크로 선택하기

이제 브라우저 STT 앱의 마이크 목록에 CABLE Output이 보일 거예요.

앱에서 확인할 것
  • ☑ "녹음 장치" 드롭다운에서 CABLE Output 선택 (앱이 자동으로 골라줄 수도 있어요)
  • ☑ "원음 그대로(가상마이크용)" 체크 — VB-Cable로 들어오는 소리는 사람 목소리가 아니라서, 노이즈제거 기능을 끄는 게 더 깨끗하게 잡혀요
  • ☑ Windows 소리 설정에서 기본 입력 장치도 CABLE Output으로 되어 있는지 확인 (STT 자체는 이 "기본 장치"를 사용해요)

05 노트북이라 VB-Cable을 못 깔 때

일부 노트북은 별도 설치 없이 같은 기능을 이미 갖고 있어요.

스테레오 믹스(Stereo Mix) 확인

Realtek 오디오가 내장된 노트북이라면, 녹음 장치 목록에 스테레오 믹스(Realtek(R) Audio)가 이미 있을 수 있어요. 있으면 이게 VB-Cable과 똑같은 역할을 해요 — 설치 없이 그대로 쓰시면 됩니다.

🔊 스테레오 믹스는 "청취"를 켜지 마세요
VB-Cable과 달리 스테레오 믹스는 스피커 소리를 그대로 복사해서 가져오는 방식이라, 이미 스피커로 소리가 나가고 있어요. 여기에 "청취"까지 켜면 소리가 겹쳐서 울리는(에코) 문제가 생겨요. 스테레오 믹스는 청취 설정을 건드리지 않고 그대로 두는 게 정답이에요.

06 자주 겪는 문제

직접 겪었던 증상들 위주로 정리했어요. 항목을 눌러 펼쳐보세요.

마이크는 신호가 잡히는데, 녹음해보면 소리가 없어요 +

십중팔구 노이즈제거(noiseSuppression) 때문이에요. 이 기능은 "사람 목소리"를 전제로 만들어져서, VB-Cable로 들어오는 시스템 소리를 노이즈로 착각해 억눌러버려요.

해결: 앱의 "원음 그대로(가상마이크용)" 체크박스를 켜세요.

소리가 울리거나 겹쳐 들려요 (에코) +

스테레오 믹스를 쓰는데 "청취"를 켜셨거나, VB-Cable의 청취 재생 장치가 잘못 지정된 경우예요.

  1. 스테레오 믹스라면 → 청취 설정을 끄세요 (원래 필요 없음)
  2. VB-Cable이라면 → 청취의 재생 장치가 CABLE Input 자신이 아니라 실제 스피커로 되어 있는지 확인
삐- 하는 피드백음(경보음)이 계속 나요 +

소리가 스스로를 반복해서 되돌리는 피드백 루프예요. 급하면 먼저 음소거하고, 원인을 찾으세요.

  1. 녹음 탭 → 문제의 장치(스테레오 믹스/CABLE Output) → 속성 → 청취 탭 → 체크 해제
  2. 그래도 안 멈추면 재부팅 (오디오 설정 꼬임은 재부팅으로 대부분 리셋됨)
재생장치 목록에 아무것도 안 뜨고 "출력 장치를 찾을 수 없습니다"라고 나와요 +

VB-Cable/가상장치 문제가 아니라, 노트북 자체의 오디오 드라이버가 꼬인 경우예요.

  1. Windows 오디오 문제 해결사 실행 (설정 → 시스템 → 소리 → 문제 해결)
  2. 장치 관리자에서 사운드 장치에 노란 느낌표(⚠) 있는지 확인
  3. 그래도 안 되면 재부팅, 최후엔 오디오 드라이버 재설치
녹음 장치 드롭다운에 "기본값"/"통신" CABLE Output이 두 개씩 보여요 +

정상이에요. Windows가 같은 장치를 "일반 용도"랑 "통화 앱 전용"으로 나눠서 두 번 보여주는 거예요. "기본값 - CABLE Output"을 선택하시면 됩니다.
