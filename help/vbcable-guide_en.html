Use System Audio as a Microphone

For STT to understand sound playing from YouTube or a video, you need a bridge that turns your speaker output into a virtual "microphone input." VB-Cable is that bridge.

01 Install

Free download from the official site. A restart is required after installation.

Download from the official VB-Audio site

Click "Download" on the page below to get the zip file.

vb-audio.com/Cable →

Unzip it, then run VBCABLE_Setup_x64.exe as administrator (right-click → "Run as administrator").

⚠ Required after install
Once installation finishes, restart your computer. Skipping the restart often means the device won't show up in any list, or no audio gets captured at all.

02 Route system audio into CABLE

This tells Windows to send audio to VB-Cable instead of your speakers.

Set your output device to CABLE Input
Settings› System› Sound› Choose where to play sound

Select CABLE Input (VB-Audio Virtual Cable).

🔇 Side effect - you won't hear anything
With this set, all audio goes to CABLE only, so nothing plays through your speakers/headphones. STT works fine, but you personally can't hear it. Step 03 below fixes that.

03 Make it audible to you too

This keeps STT capturing audio while also sending sound to your speakers. Getting this step wrong can cause echo or a screeching feedback tone.

Turn on "Listen to this device"
Sound settings› Recording tab› Right-click CABLE Output› Properties› Listen tab

Check Listen to this device, then set the playback device to your actual speakers/headphones.

⚠ Only enable this in one place
Turn on "Listen" only for CABLE Output. If you accidentally set its playback device to CABLE Input itself, the sound feeds back into itself endlessly, producing a screeching feedback tone (sounds like an alarm). If you hear that, immediately turn "Listen" off and re-check your settings.

04 Select it inside the STT app

CABLE Output should now appear in the app's microphone list.

What to check in the app
  • ☑ Select CABLE Output in the "Recording device" dropdown (the app may auto-select it for you)
  • ☑ Enable "Raw audio (for virtual mic)" — audio coming through VB-Cable isn't a human voice, so turning off noise suppression captures it more cleanly
  • ☑ In Windows Sound settings, confirm CABLE Output is also set as the default input device (STT itself relies on this "default device")

05 On a laptop where you can't install VB-Cable

Some laptops already have the same capability built in, no install needed.

Check for Stereo Mix

If your laptop has Realtek audio, the recording device list may already include Stereo Mix (Realtek(R) Audio). It does exactly what VB-Cable does — just use it as-is.

🔊 Don't enable "Listen" for Stereo Mix
Unlike VB-Cable, Stereo Mix works by directly copying your speaker output — sound is already reaching your speakers. Turning on "Listen" on top of that duplicates the audio and causes echo. Leave Stereo Mix's Listen setting untouched.

06 Common issues

Organized around symptoms actually encountered while building this. Click to expand.

The mic shows a signal, but recordings come out silent +

Almost always noise suppression. It's built assuming a human voice, so it treats VB-Cable's system audio as "noise" and suppresses it.

Fix: enable "Raw audio (for virtual mic)" in the app.

Audio sounds doubled or echoing +

Either "Listen" is turned on for Stereo Mix, or VB-Cable's Listen playback device is set incorrectly.

  1. Using Stereo Mix → turn Listen off (it's not needed there)
  2. Using VB-Cable → confirm Listen's playback device is your real speakers, not CABLE Input itself
A continuous screeching/alarm-like tone won't stop +

This is an audio feedback loop. Mute first, then find the cause.

  1. Recording tab → the device in question (Stereo Mix / CABLE Output) → Properties → Listen tab → uncheck it
  2. If it keeps going, restart your PC (a stuck audio config is usually reset by a reboot)
The output device list is empty, saying "No output device found" +

This isn't a VB-Cable/virtual-device issue — it's the laptop's own audio driver acting up.

  1. Run the Windows audio troubleshooter (Settings → System → Sound → Troubleshoot)
  2. Check Device Manager for a yellow warning (⚠) on any sound device
  3. If that doesn't help, restart, and as a last resort reinstall the audio driver
The recording device dropdown shows two CABLE Output entries ("Default" / "Communications") +

That's normal. Windows splits the same device into a "general purpose" entry and a "calling apps only" entry. Just pick "Default - CABLE Output".
